Tentang

Pro Circuit Teamfight Tactics adalah liga kompetitif papan atas Riot yang mempertemukan 128 pemain elite dari empat regional: AMER, APAC, EMEA, dan Cina.

Di setiap set, para pemain Pro Circuit berkompetisi dalam serangkaian event regional. Perjalanan ini mengarah ke Regional Final, saat para pemain bersaing untuk melaju ke TFT Pro Circuit set berikutnya, dan lolos ke Tactician's Crown, untuk menentukan satu pemain sebagai juaranya.

LIHAT DETAIL

01

Dapatkan Kartu Compete

Langkah pertama dalam perjalananmu menuju pro adalah mendaftarkan Kartu Compete, ID pribadimu untuk segala hal terkait TFT kompetitif. Dengan mendaftarkan kartu ini, kamu akan bisa membuka pendaftaran event, melacak kualifikasi event dan progres di tangga peringkat, serta menghubungkan semua aktivitasmu menuju Pro Circuit.

DAPATKAN KARTU COMPETE

02

Daftar ke Event

Daftar turnamen Tactician's Cup untuk menyatakan keinginanmu berkompetisi dalam sirkuit Tier 2. Jangan lupa periksa jadwalnya untuk melihat waktu buka dan tutup periode pendaftaran turnamen!

LIHAT JADWAL

03

Ikuti Kualifikasi & Berkompetisi

Kamu akan berkompetisi dalam Ladder Ranked server regionalmu untuk bisa lolos ke event Tactician's Cup yang kamu ikuti. Jangan khawatir. Jika kamu tidak lolos ke Tactician's Cup, kamu masih punya kesempatan kedua untuk bisa lolos melalui Tactician's Trials.
