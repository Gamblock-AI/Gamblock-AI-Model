Program Studi

Program Sarjana

Kami menawarkan 34 program studi unggulan yang siap membawamu menuju masa depan gemilang. Pilih jurusan sesuai minat dan bakatmu, dan mulai perjalanan akademikmu bersama kami.

Program
Profesi

Program profesi dirancang khusus bagi lulusan dari program studi tertentu sebagai syarat meraih gelar keprofesian, seperti Profesi Dokter dan Profesi Guru. Program ini menjadi jembatan penting menuju dunia kerja profesional yang sesungguhnya.

Program Magister

UM Palembang membuka kesempatan untuk melanjutkan pendidikan ke jenjang Magister (S2) dan Doktor (S3) melalui berbagai program studi yang dikelola oleh Program Pascasarjana. Wujudkan karier dan keahlian yang lebih tinggi bersama kami.
