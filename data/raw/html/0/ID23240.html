AIMP6 Beta

Artem | 2026-03-16 09:00:00 | Views: 1005494

We have started public beta-testing of AIMP6 for PC!



This is the first truly cross-platform version of the player for PC. AIMP is now capable to run on Linux without Wine!

What's new?
  • Overview of AIMP6 features
  • Differences in player functionality between Windows and Linux

Join to beta-testing

Please report about all issues via feedback channels and our forum.

Please read the beta-testing rules before sending the report. Please describe in detail the situation in which an error occurred, or provide step-by-step instruction to reproduce it. Do not forget to specify full app version and information about your OS (name, version and desktop environment).

Warning!

If you've been considering switching to Linux but haven't done so yet, it's not a good idea to start by installing AIMP. We can't help you get learn the OS.

Note that version is in testing stage, it may contain many bugs!
Please do not use it in work where stability and software quality are important.
