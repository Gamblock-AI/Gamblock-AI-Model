Key Features

Some of the Key Features of News X Free Theme

Easy Header Footer Builder

Easy-to-use drag-and-drop header and footer builder built into the WordPress theme customizer – create stunning headers and footers on the go!

Built in WordPress Widgets

Comes with essential widgets like Post Grid, Magazine Grid, Post List widget, Featured Post widget, Popular Post widget, Subscription widget, and much more.

Live Edit with WP Customizer

All site parts, like the header, footer, home page, blog page, single page, and other pages, can be edited live via the WordPress Live Customizer on the go!

Responsive & Retina

News X Theme adapts to any kind of device screen, from mobile phones to high-resolution Retina displays.

Translation Ready

Each hard-coded string is ready for translation. The theme is compatible with all modern translation plugins.

SEO Optimization

The Theme is coded with SEO in Mind. Compatible with the most popular SEO optimization plugins.
