  • PENGELOLA SANDI

    Gunakan sandi yang kuat di setiap situs.

    Chrome memiliki Pengelola Sandi Google bawaan yang memudahkan Anda menyimpan, mengelola, dan melindungi sandi Anda secara online. Fitur ini juga membantu Anda membuat sandi yang lebih kuat untuk setiap akun yang Anda gunakan.

  • SAFE BROWSING YANG DISEMPURNAKAN

    Menjelajah dengan keyakinan bahwa Anda tetap aman saat online.

    Safe Browsing Chrome memperingatkan Anda tentang serangan malware atau phishing. Aktifkan Safe Browsing yang Disempurnakan untuk perlindungan keamanan yang lebih baik.

  • PEMERIKSAAN KEAMANAN

    Periksa tingkat keamanan Anda secara real time, hanya dengan satu klik.

    Pemeriksaan Keamanan Chrome memastikan keamanan dan privasi menyeluruh selama Anda menjelajah, termasuk sandi, ekstensi, dan setelan yang Anda simpan. Jika ada hal yang perlu diperhatikan, Chrome akan membantu Anda memperbaikinya.

  • PANDUAN PRIVASI

    Kelola privasi Anda dengan setelan yang mudah digunakan.

    Chrome memudahkan Anda mengetahui info yang Anda bagikan di internet dan kepada siapa Anda membagikannya. Cukup gunakan Panduan Privasi, panduan yang menjelaskan setelan privasi Anda langkah demi langkah.

Pertanyaan umum (FAQ)

Bagaimana cara menginstal Chrome?

Untuk menginstal Chrome, cukup download file penginstalan, lalu cari di folder download Anda. Buka file dan ikuti petunjuknya. Setelah Chrome diinstal, Anda dapat menghapus file penginstalan. Pelajari lebih lanjut cara mendownload Chrome di sini.

Apakah Chrome berfungsi di sistem operasi saya?

Chrome kompatibel dengan perangkat yang menjalankan sistem operasi Windows dan Mac, asalkan memenuhi persyaratan sistem minimum. Untuk menginstal Chrome dan menerima dukungan yang memadai, Anda harus memenuhi persyaratan sistem. Pelajari lebih lanjut cara menggunakan Chrome di perangkat Anda.

Bagaimana cara menjadikan Chrome sebagai browser default saya?

Anda dapat menjadikan Chrome sebagai browser default di sistem operasi Windows atau Mac serta perangkat iPhone, iPad, atau Android. Jika Anda menjadikan Chrome sebagai browser default, semua link yang Anda klik akan otomatis dibuka di Chrome. Temukan petunjuk spesifik untuk perangkat Anda di sini.

Apa itu setelan keamanan Chrome?

Chrome menggunakan fitur keselamatan dan keamanan yang canggih untuk membantu Anda mengelola keamanan. Gunakan Pemeriksaan Keamanan untuk langsung mengaudit sandi yang telah dibobol, status Safe Browsing, dan semua update Chrome yang tersedia. Pelajari lebih lanjut keselamatan dan keamanan di Chrome.

Gunakan browser Anda dari mana saja

Download Chrome di perangkat seluler atau tablet, lalu login ke akun Anda untuk mendapatkan pengalaman browser yang sama, di mana saja.
