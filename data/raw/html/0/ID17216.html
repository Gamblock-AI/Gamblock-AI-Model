Klik Tombol Dibawah Ini Untuk Masuk

NontonGP

Tombolnya di atas tulisan ini, kotak merah yang ada tulisan NontonGP

Alamat streaming akan selalu berganti. jika ingin tetap mudah bisa mengakses NontonGP.ORG atau free.nontonx.com silahkan ubah DNS ke Secured DNS. Cara ubah Secured DNS ada di bawah ini.

Google Chrome

* Pengaturan ini mungkin sudah diaktifkan secara default.

  1. Klik menu tiga titik di sudut kanan atas jendela chrome Anda. 
  2. Klik Pengaturan. 
  3. Navigasi ke Privasi dan keamanan > Keamanan. 
  4. Aktifkan sakelar Gunakan DNS aman .
  5. Pilih dengan Kustom dari menu drop-down.
  6. Ketik Url Server DoH penyedia tepercaya Anda. 
Anda juga dapat mengetik chrome://settings/security sebagai url untuk membuka opsi keamanan

Mozilla Firefox

  1. Klik tombol menu. 
  2. Pilih Pengaturan. 
  3. Di menu Umum, gulir ke bawah untuk mengakses Pengaturan Jaringan. 
  4. Klik pada tombol Pengaturan. 
  5. Klik Aktifkan DNS-over-HTTPS. Pilih penyedia atau kustom yang sesuai dari menu drop-down.
  6. Tekan OK untuk melamar.
Anda juga dapat mengetik about:preferences#general sebagai url untuk membuka opsi keamanan
