Mengapa harus beli theme ini?

Bayangkan bagaimana jika anda membuat posting movie hanya dengan 1 kali klik maka artikel movie akan terisi dengan otomatis.

Yang perlu anda lakukan hanya mengupload video dan memasang player nya saja.

Selain fitur 1 klik post, masih banyak sekali fitur fitur yang tidak kalah keren nya, mari kita lihat fitur fitur apa saja yang ada pada theme ini.

Ajax Search

Pada versi terbaru terdapat ajax search yang memudahkan penunjung mencari film.

Movie Post Type

Pengaturan dengan data movie yang lengkap dan 1 kali klik TMDB post.

TV Show Post Type

Pengaturan dengan data TV Show dan Episode yang lengkap dan 1 kali klik TMDB post

Blog Post Type

Anda tidak perlu kuatir jika ingin membuat sebuah posting blog, sudah disediakan post type blog

Slider Homepage

Terdapat slider yang dapat memperindah website anda, dan juga dapat anda atur genre yang tampil disana hanya dengan customizer.

Support Hingga 15 Player

Jika anda memiliki video atau movie streaming lebih dari 1 server maka anda bisa membaginya dalam beberapa ajax tab, sehingga performa tetep bagus

Link Download Support

Support hingga 15 link download. Sehingga anda bisa membagikan subtitle, dan lainnya, hingga ke 10 server uploader

Advance Search Widget

Permudah pengunjung anda untuk melakukan pencarian movie di website anda.

Dengan pencarian ini, pengunjung akan lebih mudah mencari film atau movie di website anda

Best rating page

Terdapat fitur custom page untuk best rating, best rating ini berdasarkan rating di TMDB.

Order by title page

Terdapat fitur custom page untuk order by title, halaman tersebut berdasarkan urutan judul pada posting movie.

A Z Index Movie

Otomatis akan memasukkan huruf pertama pada index taxonomy, ini mempermudah visitor melakukan pencarian berdasarkan abjad

Di lengkapi dengan A Z Index custom page nya

Komentar Facebook

Ketika sobat fokus membuat berita viral di facebook, alangkah baiknya jika sobat menggunakan komentar facebook. Theme ini sudah support komentar facebook.

Simple Mega Menu

Terdapat 3 custom menu dan masing masing menu sudah support simple mega menu, sehingga anda bisa memasukkan berbagai macam url seperti country, year, genre, dll.

Popup Trailer

Tidak hanya keren theme nya, tetapi juga di lengkapi dengan popup untuk trailer, sehingga pengunjung dapat mereview terlebih dahulu film yang ingin di tonton.

Responsive dan Mobile Friendly

Desain yang sudah di optimalkan untuk semua device, baik desktop, tablet maupun ponsel.

Movie Rich Snippet

Struktur SEO Rapi, tetapi juga harus didukung dengan rich snippet yang baik. Theme ini sudah mendukung rich snippet movie dan tidak terdapat error rich snippet.

Infinite Scroll Support

Seperti theme wordpress berita besar indonesia lainnya, theme ini sudah support infinite scroll.

Fixed scroll top navigation, banner dan sidebar

Tampilan web berita semakin interaktif dengan adanya fixed top navigation, banner, dan di sidebar.

FB Pixel dan Google Analytics

Tersedia opsi untuk memasukkan facebook pixel id dan google analytics code. Ini bisa anda gunakan untuk menganalisi pengunjung anda dan untuk keperluan FB ads anda.

One Click Update dan Import

Unlimited Color
