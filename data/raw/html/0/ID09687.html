Auto Saving

Hanya Bayar Sesuai Konsumsi Resource VPS Anda

Jagoan Cloud bekerja secara otomatis dengan menaikkan atau menurunkan resources server, dengan menyesuaikan aktifitas server. Dengan begitu Anda akan menghemat dari sisi biaya dan resources yang dikeluarkan.

Auto Hibernate

VPS Masuk dalam Mode Nonaktif Ketika Tidak Ada Aktifitas

Server akan otomatis masuk mode hibernasi saat tidak ada penggunaan resource sama sekali selama 3 hari berturut-turut, saldo anda akan benar-benar menjadi hemat karena anda hanya akan dibebani biaya storage saja. Hal ini tentu akan memudahkan Anda yang mungkin tidak akan setiap waktu memonitoring server.

Auto Scaling

Resource VPS Otomatis Bertambah atau Berkurang Saat Dibutuhkan

Scaling infrastruktur, bisa dilakukan secara otomatis, Seperti “Turunkan penggunaan RAM ke 4GB saat penggunaan rata-rata hanya 30%”. Atau kondisi saat 1 server dirasa kurang, maka secara otomatis akan menambah server baru dan jika tugas di server sudah rendah, salah satu server akan dihapus.

Budget Prediction

Prediksi Konsumsi Saldo dan Pantau Melalui Riwayat Laporan

Anda tidak perlu khawatir saldo Anda tiba-tiba habis, karena di Jagoan Cloud terdapat fitur prediksi konsumsi saldo, yang tersedia untuk kurun waktu tiap jam, hari dan bulan. Bahkan di sana juga disediakan laporan pemotongan saldo, yang Anda bisa evaluasi jika dibutuhkan.

Dukungan Lain Guna Memaksimalkan Pemanfaatan Jagoan Cloud untuk Kebutuhan Anda_

Fitur lengkap Jagoan Cloud yang dapat Anda manfaatkan sesuai kebutuhan

Docker Hub

Langsung pakai ribuan docker images yang tersedia, seperti install aplikasi pada play store atau apps store.

Instant Cloning

Sebelum upgrade, Anda bisa clone server Anda terlebih dahulu (staging) agar Anda punya backup instant untuk server ketika terjadi hal yang tidak diinginkan.

Out Of Memory Killer

Terdapat fitur Out of Memory Killer, sehingga mustahil server Anda mati hanya gara-gara pelanggan lain ‘mencuri’ resource server Anda.

Multiple IP Public

Atur sendiri berapa jumlah IP Public yang Anda butuhkan. Jagoan Cloud juga sudah mendukung IPv6.

Build-in Monitoring

Tersedia email notification untuk kebutuhan monitoring server Anda, seperti informasi load server, saat ada server mati, dsb.

SSL Ready

Cukup sekali klik untuk bisa pasang SSL di Jagoan Cloud. SSL yang Anda pasang sudah langsung auto Renew, hal ini untuk menjaga transaksi data Anda terus terjaga.

Frequently Asked Question_

Yang paling sering ditanyakan

Apakah arti dari Managed VPS di Jagoan Cloud?

Kami menyediakan platform untuk Anda me-’manage’ VPS dengan mudah. Sehingga Anda tak perlu harus buru-buru merekrut tim infrastruktur sendiri.

Apakah saya dibantu instalasi awal untuk kebutuhan infrastruktur aplikasi atau website saya?

Kami menyediakan berbagai macam service, tools, aplikasi yang menjadi standar kebutuhan sebuah aplikasi atau website. Anda tinggal memilihnya nanti saat Anda hendak membuat sebuah server di Jagoan Cloud. Platform kami akan memasang sesuai apa yang Anda pilih dan butuhkan. Sebagai contoh, Anda ingin menggunakan docker atau web server+database, Anda tinggal pilih saja di marketplace yang tersedia di dalam platform kami, sistem akan menyiapkannya untuk Anda secara cepat.

Apakah saya dibantu memonitoring infrastruktur saya disini?

Ya, kami adalah bagian dari Jagoan Hosting yang telah ter-sertifikasi ISO 27001. Ini adalah bentuk komitmen kami untuk memastikan keamanan infrastruktur Anda. Kami selalu memantau server-server kami untuk selalu aman dari serangan, dimana kami juga menyediakan firewall tambahan untuk keamanan berlapis.

Bagaimana jika aplikasi saya terinfeksi malware?

Selama malware tersebut tidak menyerang script yg Anda buat, atau masih ada di layer aplikasi, maka Anda akan selalu bisa melakukan ‘deploy’ ulang aplikasi Anda dan semua akan kembali seperti semula. Untuk itu, Anda perlu memastikan topologi infrastruktur Anda memanfaatkan kelebihan Jagoan Cloud, dimana Anda tidak perlu menempatkan seluruh telur dalam satu keranjang.

Bagaimana dengan update, apakah dibantu juga?

Saat ada update baru dari service, tools, aplikasi yang Anda gunakan, kami akan menyediakannya di platform kami. Anda tinggal pilih saja mana yang ingin Anda update, dan versi mana yang ingin Anda gunakan. Tinggal klik, lalu sistem kami akan memperbaruinya secara cepat. Enak sekali kan? Anda memiliki kendali penuh disini, tinggal pilih, sistem kami yang melakukannya untuk Anda
