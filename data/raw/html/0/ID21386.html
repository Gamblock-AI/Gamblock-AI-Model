    About the Windows Insider Program

    Benefits of the Windows Insider Program

    Get early access to the latest Windows features and give feedback

    Be the first to preview the new features and updates to Windows and let us know what you think in the Feedback Hub.

    Learn what's happening

    Learn about the latest program news, updates and insights via flight blog posts, email, and social media.

    Connect with the Windows Insider team and community

    Engage with Microsoft experts and the worldwide community of Windows Insiders via our social, community forum, and at key Microsoft events.

    How to become a Windows Insider?​

    1

    Join the program

    Register for free to join a community of millions of Windows fans who love being on the cutting edge and want to help shape the future of Windows.

    Register now
    2

    Preview Windows

    Preview the latest Insider builds and features by running Windows Insider Preview Builds.

    Start previewing Windows
    3

    Influence the future​​

    Once you're running Windows Insider Preview Builds, give us feedback on the features, changes, and issues you're seeing in the Feedback Hub.

    Provide feedback

    Insider Channels

    Learn more about the channels and latest builds.

    Canary Channel

    Ideal for highly technical users.

    Preview the latest platform changes early in the development cycle.

    These builds can be unstable and are released with limited to no documentation.

    Latest Canary Channel 28000 series build
    Latest Canary Channel 29500 series build (optional)

    Dev Channel

    Ideal for enthusiasts.

    Access the latest Windows 11 preview builds as we incubate new ideas and develop long lead features.

    There will be some rough edges and low stability.

    Latest Dev Channel build

    Beta Channel

    Ideal for early adopters.

    Preview and provide feedback on pre-release features for Windows 11 in a stable environment.

    Latest Beta Channel build

    Release Preview Channel

    Recommended for commercial users.

    Ideal if you want to preview fixes and certain key features, plus get optional access to the next version of Windows before it’s generally available to the world.

    Latest Release Preview Channel build
