More details

You can use draw.io to visualize everything:

  • Process Modeling and Relationships (BPMN 2.0, ERD, Flowcharts, Swimlane diagrams…)
  • Software Development and Networks (UML, UML 2.5, AWS, Azure, Cisco, GCP, IBM…)
  • Administration (Org charts, Mindmaps, Floorplans, Infographics)
  • Support case flowcharts
  • AI-driven Smart Templates for all of the use cases mentioned above
  • And more

Versatility isn't the only reason why thousands of businesses and millions of global users rely on draw.io. With enterprise-grade security and privacy standards, no diagram data ever leaves your instance.

Switching from Visio or Gliffy to draw.io is just as easy. Are you running Confluence AND Jira? Then we recommend using draw.io in Confluence and linking your diagrams to Jira, as the Confluence app has enhanced features such as whiteboarding and revision history.

Version information

Version 2.1.0•for Jira Cloud

Release date
Oct 21st 2024
Summary
Switches app to Forge listing
Details

Forge is Atlassian's next generation of application interface for building apps. This release is the first step is moving towards Forge, from the existing Connect architecture.

This release is exactly the same functionality-wise, but the manifest listing is now Forge based, instead of Connect based.

This means that your Jira cloud admin will have to manually approve installation of the app in the admin "manage apps" section. They need to do this in the next 6 months to be able to continue using draw.io in Jira cloud.
