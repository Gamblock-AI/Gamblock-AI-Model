More Exposure: The Network Effect

When you join App Pass, you are joining a network of premium extensions. The success of any extension in the network benefits everyone.

1. User Discovery

User discovers a participating extension (e.g. Extension A) via Chrome-Stats or Stores.

2. App Pass

User subscribes to App Pass to unlock premium features for Extension A.

3. Unlock All

User automatically gets premium access to Extension B, C, and all others.

4. Shared Growth

User starts using other extensions in the pass, generating revenue and exposure for everyone.

Higher Conversion

The subscription model eliminates the decision fatigue associated with individual purchases. Users are far more likely to subscribe to a bundle that offers significantly more value than the cost.

1. Massive Value

Users get access to your extension plus dozens of other premium tools.

2. Clear Bargain

The $10 monthly fee is tiny compared to the combined value of all extensions ($100+).

3. Frictionless Buy

The "no-brainer" value proposition leads to higher conversion and reduce churn.

Revenue Model

The revenue from App Pass is distributed to developers based on the following model:

  1. User Activation: When a user activates App Pass for an extension, we mark that extension as activated on our server side. The activation is done on our website after confirming with the user (similar to OAuth), so the extension cannot automatically activate App Pass using the SDK.
  2. Daily Calculation: Each day, we calculate the number of activated extensions for a user.
  3. Revenue Distribution: We take the monthly subscription fee $10 - $2 platform fee = $8, partition it into number of days in a month (e.g., $8 / 30 days ~= $.266), and distribute that among the activated extensions on that day. So if the user has activated 2 extensions on that day, then each get ~= $.133.
  4. Continuous Accumulation: The accumulation will continue for a given extension until the user deactivate the extension on the App Pass dashboard, or if the user's subscription ended / expired. So if a user has 2 activated extensions for a given month, each extension should earn $4 for that month.
  5. Dashboard Transparency: The App Pass partner dashboard will show an estimated earning so far, and the number of activated users. This is updated daily so it may have up to 24 hours lag.

Frequently Asked Questions

Who can apply?

Any developer with a public listing extensions.

What are the extension eligibility requirements?

We only accept publicly accessible browser extensions. Extensions must not contain spyware or malware. Themes are not supported.

How to integrate with App Pass?

We provide an official SDK for integration. Please refer to our integration guide or the @chrome-stats/app-pass-sdk for documentation and usage examples.

Can I have my own payment setup?

Yes! Extensions can have their own payment model in addition to using App Pass.

When will I get paid?

We will pay developers using PayPal at the beginning of each month once the payout crosses the $50 threshold.

What is the "Notify Integration Done" button for?

Once you have finished integrating the App Pass SDK and published the update to the respective extension store, click this button to notify our team. We will then review your integration, and once verified, we will mark your extension as "Live" and promote it on our main page to help you get more users.
