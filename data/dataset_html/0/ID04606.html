Help

How to use the accessibility plugin?

You can show the accessiblity plugin any time by clicking on the keyboard keys ALT and Z or on the relevant accessibility button on this website (usually indicated by a person on a wheelchair). You can then use the different options to adjust the according to your accessibility needs.

Additionallly, you may change the accessibility plugin settings as you wish (such as changing the language, showing helpful tips etc). Your accessibility options and settings will be saved and activated automatically while you're visiting this website. You can reset the accessibility settings any time by clicking on the keyboard keys ALT and X.

A lot of work and efforts were put into this plugin and we hope it will help you enjoy the contents our website has to offer.

How to use the accessibilty plugin options?

Every option of the plugin can be activated and deactivated with a mouse click or the Enter key. Additionally, you can navigate the options using the keyboard left and right keyboard keys. When an option is activated, it will usually be marked with a checkmark sign and will have a background color.

Keyboard shortcuts of the accessibility plugin

The accessibility plugin has a list of keyboard shortcuts you can use to operate it:

ALT and Z - Show and hide the accessibility plugin.

ALT and X - Show help inside the plugin options. Repeating this combination will undo this option.

ALT and C - Reset the accessibilty options set by the plugin.

ALT and V - Quick navigation to the top of the page.

ALT and B - Quick navigation to the bottom of page.

SHIFT and A - Enlarge the text of the page.

SHIFT and S - Shrink the text of the page.

SHIFT and D - Highlight the links on the page. Repeating this combination will undo this option.

SHIFT and F - Highlight the titles on the page. Repeating this combination will undo this option.

SHIFT and Q - Activate the option 'Color blind' (Gray colors). Repeating this combination will undo this option.

SHIFT and W - Activate the option 'Impaired vision' (Inverted colors). Repeating this combination will undo this option.

SHIFT and E - Activate the option 'Bold colors' (Saturated colors). Repeating this combination will undo this option.

About this accessibility plugin

This website is using NagishLi, an accessibility plugin developed by Localize to help improve website browsing experience for people with disabilities.

When accessibility became required by law in Israel, many website owners had to make some decisive actions with financial consequence. Localize had to look for a solution - but almost every possible solution was either built mainly for WordPress, had monthly costs, or required changing the website source code...

Understanding that every website owner has the right to offer accessibility options for people with disabilites and also help people with disabilities make the best of websites on the internet as equals, NagishLi has set a goal to be an advanced, free accessibility plugin for all.
