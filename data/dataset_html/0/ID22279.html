Download Cave Story

Note: For Cave Story WiiWare, Cave Story+, Cave Story DSi, or Cave Story 3D please click here.

Note on NXEngine: NXEngine is an open source reproduction of the Cave Story engine. Most of the other ports here are built using the original source code from Pixel, but NXEngine ports are built from a fork of the NXEngine source core, at any stage of NXEngine's development. Chances are that the differences will be unnoticeable or really minor to most, but it is worth keeping in mind.

Note on NXEngine-evo: NXEngine-evo is a fork of NXEngine whose primary feature is widescreen support.

Note on CSE2: CSE2 is another open source reproduction of the Cave Story engine, except it is designed for accuracy and faithfulness to the original. Sadly, the source code was subject to a DMCA takedown.

Note on doukutsu-rs: A reproduction of the Cave Story engine written in Rust.

Deluxe Package

In 2006 Wadeizzle made an installer for Cave Story called Cave Story Deluxe. The name caused misconceptions because it didn't add anything new to Cave Story that wasn't already present... it just housed a bunch of extra stuff (like Ikachan, Orgmaker, etc.) under one installer. However... putting Cave Story in the Program Files folder makes save management painful, as such the installer download link has been removed and you can instead download the contents of the package below if you wish to.

SerenityOS Port by gloof (listing page)  

Note: You can install Cave Story on SerenityOS by running the following commands in sequence within SerenityOS's build directory:

sudo apt update
sudo apt install imagemagick
git pull origin master
Meta/serenity.sh rebuild-toolchain
cd Ports/cavestory
./package.sh
cd ../..

The next time you run this command:
Meta/serenity.sh run
...Cave Story will be available on SerenityOS.
