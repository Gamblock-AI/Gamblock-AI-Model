Apa itu PANDI?

Pengelola Nama Domain Internet Indonesia atau PANDI merupakan organisasi nirlaba berbentuk perkumpulan berbadan hukum yang beranggotakan para pemangku kepentingan internet Indonesia. PANDI dibentuk oleh komunitas internet Indonesia bersama Pemerintah Indonesia pada tahun 2006 sebagai Registri Tingkat Tinggi Nama Domain Indonesia (.id) atau Country Code Top Level Domain Indonesia. PANDI memiliki anggota dari berbagai pemangku kepentingan baik dari unsur pemerintah, masyarakat, asosiasi dan para pelaku industri internet.

Selengkapnya

Mengapa harus .id?

Domain adalah alamat identitas pribadi / kantor / toko / organisasi kamu di dunia digital. Sifat Domain adalah unik, hanya ada 1 domain untuk 1 pemilik. Nama Domain berfungsi untuk mempermudah akses ke website kamu. Domain .id merupakan Nama Domain Tingkat Tinggi Indonesia dengan kode Negara Indonesia (.id). Domain .id merepresentasikan identitas Indonesia sehingga masyarakat Indonesia lebih mudah mencari website kamu. Selain itu, Domain .id juga merupakan Domain yang terpercaya, andal dan aman sehingga dapat diakses dengan cepat dan mudah.

Selengkapnya

Banyak Pilihan

Domain .id memiliki banyak pilihan yang dapat disesuaikan dengan kebutuhan kamu. Untuk mendaftarkan Domain tersebut, kamu dapat menghubungi Registrar yang terakreditasi oleh PANDI.
