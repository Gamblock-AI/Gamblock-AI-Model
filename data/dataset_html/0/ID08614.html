Platform: Android
Destek: Shoutcast / Icecast
Yayın Formatı: MP3 / AAC

Kurulum ve Ayarlar
  1. Uygulamayı açın ve sağ üst köşedeki 3 nokta (⋮) menüsüne tıklayın.
  2. Output Mode'u "Icecast V2 Server" olarak ayarlayın.
  3. Output Settings menüsüne girin ve şu ayarları yapın:
    • Hostname: Sunucu IP adresinizi girin
    • Port: 8000 (varsayılan)
    • User Name: Kullanıcı adınızı girin
    • Password: Yayın şifrenizi girin
    • Mount Point: /live (veya verilen mount point)
  4. MP3 Encoder Bitrate'i 64kbps veya 128kbps olarak ayarlayın.
  5. Auto reconnection seçeneğini aktif edin.
  6. Ana ekranda yayın başlatma butonuna basın.

VU Meters ve Fader kontrolleri ile ses seviyelerini ayarlayabilirsiniz.

BUTT (Broadcast Using This Tool)

🏆 %100
İndir
📱
📥 0 Haylaz'ten İndirme
☆ ☆ ☆ ☆ ☆
0.0/5 (0 oy)

Platform: Masaüstü
Destek: Shoutcast / Icecast
Yayın Formatı: MP3 / Ogg

Kurulum ve Ayarlar
  1. BUTT programını başlatın.
  2. Ana pencerede Settings butonuna tıklayın.
  3. Açılan Settings penceresinde Server Settings altında ADD butonuna basın.
  4. Add Server bölümünde şu bilgileri girin:
    • Server Type: Icecast veya Shoutcast seçin
    • Address: Sunucu IP adresinizi girin
    • Port: 8000 (varsayılan)
    • Password: Yayın şifrenizi girin
    • Icecast User: source (varsayılan)
    • Icecast Mountpoint: /live veya verilen mount point
  5. Audio sekmesine geçin ve şu ayarları yapın:
    • Audio Device: Mikrofonunuzu veya ses kartınızı seçin
    • Codec: MP3 veya AAC seçin
    • Bitrate: 128k (önerilen) veya 192k
    • Samplerate: 44100 Hz (önerilen)
  6. Ayarları Save butonu ile kaydedin.
  7. Ana pencerede Play (▶) butonuna basarak yayına başlayın.

İpucu: Yayın durumunu ekranın alt kısmındaki status bar'dan takip edebilirsiniz.

0.0/5 (0 oy)

Platform: MacOS
Destek: Shoutcast / Icecast
Açıklama: Nicecast'in yerini alan profesyonel Mac uygulaması

Kurulum ve Ayarlar
  1. Audio Hijack'i Rogue Amoeba'dan indirin ve kurun.
  2. Uygulamayı açın ve "New Session" butonuna tıklayın.
  3. Ses kaynağını seçin:
    • System Audio: Tüm sistem sesleri için
    • Input Device: Mikrofon için
    • Application Audio: Belirli uygulama için
  4. Sağ taraftaki "Blocks" menüsünden "Broadcast" block'unu session'a sürükleyin.
  5. Broadcast block'una çift tıklayarak ayarları açın.
  6. Broadcast ayarlarını yapın:
    • Server Type: Icecast veya SHOUTcast
    • Server Address: Sunucu IP adresi
    • Port: 8000
    • Password: Yayın şifresi
    • Mount Point: /live
    • Format: MP3 veya AAC
    • Bitrate: 128 kbps
  7. Session penceresinde "Start Session" butonuna basın.
  8. Broadcast block'undaki "Broadcast" butonuna basarak yayını başlatın.

Pro İpucu: Effects block'ları ile ses işleme de yapabilirsiniz.
