Engineering and Development Updates

Python Security Response Team (PSRT) and PEP 811

PEP 811 was approved by the Steering Council late last year. Now in 2026, PSF Security Developer in Residence Seth Larson is beginning the roll-out of the new processes and policies for the security team. There is now a public list of PSRT members and admins as well as documentation on the responsibilities and onboarding process for new PSRT members.

Since the approval of PEP 811, there have been seven new members added to the PSRT (Jacob Coffee, William Woodruff, Petr Viktorin, Stan Ulbrych, Emma Smith, Adam Turner, and Bénédikt Tran). These are the first new PSRT members since Seth was added to the PSRT in 2023. Interested in joining? Learn more in Seth's post on the PSF Blog.

The PSRT and PSF CVE Numbering Authority published 15 vulnerability advisories in Q1. Subscribe to the security-announce mailing list for security updates. Thanks to all PSRT members for their contributions towards keeping the Python community safe!
 

Deprecating frequently misused API “os.path.commonprefix()”

CVE‑2026‑1703 is a vulnerability affecting the pip installer tool prior to version 26.0. The crux of the vulnerability was a misunderstanding of the behavior of the standard library function “os.path.commonprefix()”. The function operates on individual characters (“/”, “a”, “/”, “b”...), not on path segments (“/a”, “/b”, …), leading to a limited escape when used to sanitize archives prior to extraction. After a deep-dive into the history of this function, it was clear that the confusion around the behavior was not isolated, having resulted in multiple bugs and security vulnerabilities over ~35 years. To prevent further mis-use, the function has been deprecated in the Python standard library starting in Python 3.15.
 

PyPI JSON API now includes Ownership details

A long-standing request to include PyPI Owner/Maintainer account information in the non-standardized JSON API has been shipped. This inclusion allows developers to use the information included to associate PyPI user accounts more easily than before, replacing the need to use the XMLRPC package_roles API call, which is now considered deprecated.
Bonus! The JSON API includes Organization information as well, improving on the legacy API.


PyPI Security Grab-Bag

There’s been plenty of activity related to PyPI & Security in Q1! Here’s a couple highlights:
  • PyPI now advertises a security.txt record at https://pypi.org/.well-known/security.txt to aid with any tools or browsers looking for a programmatic way to discover PyPI’s security contacts and policies. 
  • PyPI uses the disposable-email-domains list to aid with reducing spammers, and maintains its own internal list. Sometimes there’s enough evidence to support upstreaming to help everyone else, and as a result we’ve been able to contribute more domains to the list. 
  • PyPI received just under 1,000 malware/abuse reports in Q1. Over 28% of reports were corroborated by more than one reporter, improving accuracy (confidence levels) from 89% to 96%, leading to over 40% landing in automated quarantine, protecting the Python ecosystem faster than ever. Thanks to all the community reporters for their hard work!

PSF Board Updates

Introducing the PSF Community Partner Program

The PSF is excited to introduce the PSF Community Partner Program, a new way for the PSF to support Python events and initiatives with “in-kind” assistance. Specifically, use of the PSF name and logo, and promotional support through our official social media accounts. The program grew out of our desire to continue supporting the community during the pause of our Grants Program and the feedback we received upon its pause. If you organize a Python event or initiative, you can apply to be a PSF Community Partner via a short one-page form. 

The PSF welcomes your comments, feedback, and suggestions regarding the new Community Partner Program on the corresponding Discuss thread. We also invite you to join our upcoming PSF Board or Grants Program Office Hour sessions to talk with the PSF Board and Staff synchronously. If you wish to send your feedback privately, please email grants@python.org.


Applications to Join the PSF’s Meetup Pro Network are Back Open

The PSF is happy to share that applications to join the PSF Meetup Pro Network are back open! The program covers Meetup subscription costs for qualified Python-focused groups. Applications were paused last August alongside the broader Grants Program pause, and we're glad to take this small but meaningful step forward with our community-focused programs.

To qualify, your Meetup group needs to be majority Python-related, have a Code of Conduct linked in your About section, and hold at least 2 events per year. Check out the PSF’s Meetup Pro Network page to learn more about the offering and how to apply. 


Inside the PSF’s D&I Work Group

D&I Work Group Chair Georgi Ker wrote a candid post about the PSF's Diversity & Inclusion Work Group: what it's been working on, how it restructured in 2024 to better reflect the global Python community, and where it's headed.

The group now has 19 active members representing regions across North America, South America, Africa, Asia, Europe, the Middle East, and Oceania. The group is currently focused on three initiatives: creating D&I resources for communities, writing a guide for starting local Python user groups, and continuing to collect community survey feedback. If you want to get involved or share your experiences building inclusive communities, reach out at diversity-inclusion-wg@python.org.

PSF Updates

Anthropic donates $1.5 million in the Python Software Foundation and open source security

Anthropic has entered into a two-year partnership with the PSF, donating a total of $1.5 million with an emphasis on Python ecosystem security. A portion of the funds will go toward building new tools for proactive automated review of packages uploaded to PyPI, expanding on the current reactive-only process, with outputs expected to be transferable to other open source package repositories. The rest will support the PSF's core work, including the Developer in Residence program, community grants, and PyPI infrastructure. Read the full announcement on the PSF Blog.

Jazzband 

After more than 10 years, Jazzband is sunsetting. Jazzbound founder and current PSF Board Chair Jannis Leidel shared that the cooperative open source maintainership model, which grew to 3,135 members, 84 projects, and over 150 million monthly PyPI downloads, is no longer sustainable. Open membership became untenable in a world of AI-generated spam PRs, and with the project always dependent on one person to run it, there was no suitable path forward. 

New signups are disabled, project leads will be contacted before PyCon US 2026 to coordinate transfers, and the GitHub organization will remain available through the end of 2026. Make sure to check out the full retrospective and wind-down plan for more information.
