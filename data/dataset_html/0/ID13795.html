No code

Scimago Graphica combines great versatility with the ease of use of a no code tool. Explore, filter and visualize a dataset simply by drag-and-drop.

Beyond basic charts

Scimago Graphica offers much more than a limited set of chart types to choose from. The tool integrates a graphic grammar engine which, simply by specifying which visual attributes to use to encode the variables, generates the most accurate visualization.
