What is Gamdie.com?

Gamdie.com is a site for Free Preinstalled Indie Games. The name Gamdie is combination of Game + Indie.

How to Download Games?

Open any of the game post and look for a Download buttons in the Download Links tab. It will redirect you to the mentioned site, from there you can download the Zip file of game.

How to run Games?

The games are ready to play. You simply need to Extract ZIP file and Run the Exe of the game. Detail guide can be found in "Troubleshoot" page.
